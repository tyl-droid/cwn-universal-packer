# CWN Universal Packer v0.9.0-alpha

## Release Summary

v0.9.0-alpha expands CWN Universal Packer from its core container engine into a more complete archive-management application.

This release focuses on package metadata, archive browsing, selected extraction, integrity protections, desktop interface improvements, and extraction hardening.

## Highlights

### Configurable Package Metadata

Packages now support:

- Package name
- Package version
- Publisher
- Producer identification

Metadata is available through the engine, CLI, inspection system, and desktop interface.

### Improved Archive Browser

The desktop archive workspace now includes:

- Search
- Filters
- Sortable columns
- Entry selection
- Compression statistics
- Selected-entry extraction

### Verified Selected Extraction

Individual files can be extracted directly from a CWN archive.

Selected extraction includes:

- Safe path validation
- Bounded payload reads
- Bounded decompression
- Declared-size verification
- SHA-256 verification
- Existing-file protection
- Partial-file cleanup on extraction failure

### Extraction Hardening

The extraction cleanup path now includes final output flushing.

If extraction, integrity verification, decompression, writing, or flushing fails after the destination file is created, the partial destination is removed.

### Security Validation

The test suite covers:

- Invalid container magic
- Truncated containers
- Parent traversal
- Absolute archive paths
- Duplicate paths
- Overlapping payloads
- Payload/manifest overlap
- Malformed SHA-256 metadata
- Unknown compression
- Declared-size mismatches
- Corrupt Zstandard payloads
- Existing output protection
- Empty files
- Selected extraction integrity failures
- Package metadata validation

## Known Validation Limitation

The desktop-only `eframe`/`egui` implementation was not independently compiled on a desktop target before tagging this release.

The GitHub Actions desktop validation job was prevented from starting because of an account billing restriction. The job contained zero executed steps, so this is an infrastructure limitation rather than a recorded compilation failure.

Desktop support remains alpha pending a successful desktop-target build.

## Status

This is an alpha release.

The CWN container format, metadata model, CLI, GUI, and internal APIs may continue to change before a stable release.
